# 送厂询价包

版本：v1
更新日期：2026-09-22
用途：向方案商与代工厂索取正式报价，服务路线图的 G2 决策点（2026-11-30）

> 本项目为模拟项目。本目录所有文件均为对外版本，不含定价、毛利、预测数据和内部判断。发放前请按第 4 节核对。

## 1. 发放对象与内容

目标：至少 2 家方案商与 2 家代工厂（对应假设 H02）。

| 对象 | 发放文件 | 主要回收内容 |
| --- | --- | --- |
| 方案商 | `规格书.md`、`BOM需求清单.csv`、`问询表-方案商.md` | 主控与无线方案、一键切换可行性、开发周期、方案开发费 |
| 代工厂 | `规格书.md`、`BOM需求清单.csv`、`问询表-代工厂.md` | 模具费、认证费、MOQ、阶梯单价、试产与良率 |

## 2. 回收要求

在询价函中逐项写明，避免回收后无法横向比较：

| 项目 | 要求 |
| --- | --- |
| 报价口径 | 含税与不含税分开列示，标明税率 |
| 币种 | 人民币 |
| 运费 | 是否含运，交货地点 |
| 数量阶梯 | 1 万台 / 3 万台 / 5 万台 / 10 万台四档 |
| 报价有效期 | 不少于 90 天 |
| 付款条件 | 预付款比例、账期 |
| 回收截止 | 发放后 3 周内 |
| 提交格式 | 按问询表逐条作答，不接受只给总价 |

## 3. 回收后的动作

1. 汇总各家的报价与交期，形成横向对比表。
2. 用对比结果回答 P12（四个 SKU 的模具、认证费用与 MOQ）和部分 P13（霍尔与 TMR 的成本差异）。
3. 把结果代入 `03-产品方案/单位经济模型.md`，复算固定投入是 205 万还是 360 万。
4. 提交 G2 决策。

## 4. 发放前核对：以下内容不得出现在对外文件中

| 不得外发的内容 | 原因 |
| --- | --- |
| 799 / 639 / 700 / 330 等价格数字 | 直接影响供应商报价 |
| 15 万台目标与 1.05 亿元收入目标 | 暴露采购规模，失去议价空间 |
| 毛利率、盈亏平衡与预算区间 | 同上 |
| 预测数据与 `PE` 编号 | 属内部预测，非实证 |
| `评审摘要.md` 与 `决策日志.md` | 含内部判断与取舍过程 |
| 竞品对比分析 | 属内部竞争策略 |
