# 跨平台游戏手柄 产品规格书

版本：v1

用途：供应商技术评估与报价依据

> 本文件为对外版本，只包含产品与技术要求，不含价格、数量与商务条件。商务条款以单独的询价函为准。

## 1. 产品概述

一款面向多平台玩家的无线游戏手柄，支持在 PC、Android、iOS、Switch、PS5、Xbox 之间使用，中国市场首发，目标上市时间 2027 Q3。

核心使用特征：玩家在不同平台之间切换时，按一下即可完成切换，不需要进入设置菜单选择模式，也不需要重新配对。

## 2. SKU 划分

首发共 4 个 SKU，需按独立物料与独立认证管理：

| 编号 | SKU | 说明 |
| --- | --- | --- |
| SKU-A | 通用三模版 | PC、Android、iOS（蓝牙）、Switch |
| SKU-B | PS 授权版 | 在通用版基础上支持 PS5，需对应授权方案 |
| SKU-C | Xbox 授权版 | 在通用版基础上支持 Xbox，需对应授权方案 |
| SKU-D | Lightning MFI 版 | 面向 iPhone 14 及以下设备，需 MFI 认证 |

请供应商说明：四个 SKU 是否可以共用主板或部分物料，共用与独立两种做法在成本与认证上的差异。

## 3. 连接方式与平台

| 平台 | 连接方式 |
| --- | --- |
| PC（Windows 10/11、macOS 12+） | 有线、2.4G、蓝牙 |
| Android 8.0+ | USB-C、蓝牙 HID |
| iOS / iPadOS | USB-C、Lightning（仅 SKU-D）、蓝牙 HID |
| Switch | 蓝牙、有线 |
| PS5 | 依授权方案确定 |
| Xbox Series X/S、Xbox One | 依授权方案确定 |

## 4. 功能要求

### 4.1 必须具备

| 编号 | 功能 | 技术要求 |
| --- | --- | --- |
| F01 | 一键切换 | 按一下切换到目标平台，不进入设置菜单，不重新配对；切换耗时目标 ≤3 秒 |
| F02 | 配对记忆 | 至少记住 4 个平台的配对信息，掉电 24 小时后仍保留 |
| F03 | 2.4G 连接稳定 | 连续 4 小时不出现断连 |
| F04 | 按键耐久 | 两年内不出现断触；测试标准与寿命次数请供应商建议 |
| F05 | 摇杆耐久 | 12 个月内无可感知漂移；不使用碳膜方案 |
| F06 | 摇杆方案 | 霍尔效应或 TMR，请分别报价 |
| F07 | 三模连接 | 有线 / 2.4G / 蓝牙 |
| F08 | 充电底座 | 随机标配，手柄落座即充电 |
| F09 | 磁吸键帽 | 支持在 Switch 布局与 Xbox 布局之间更换，徒手可换 |
| F10 | 独立授权 SKU | PS 与 Xbox 各自独立硬件 SKU |
| F11 | Lightning MFI SKU | 通过 MFI 认证 |

### 4.2 首批需要
