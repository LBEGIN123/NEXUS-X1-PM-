# 预测数据说明

**这个目录里的数据全部是程序生成的，不是真实调研结果。**

## 文件

| 文件 | 作用 |
| --- | --- |
| `生成预测数据.py` | 生成 300 行预测问卷数据，随机种子固定为 `20260922` |
| `问卷预测数据.csv` | 生成的原始数据，每行带 `数据性质=模拟` |
| `分析预测数据.py` | 按 `02-需求调研/分析口径与决策阈值.md` 计算全部指标 |
| `分析输出.txt` | 分析结果，供 `02-需求调研/调研分析-预测版.md` 引用 |

## 用途

两个用途：

1. 在真实问卷回收之前，验证分析流程能不能跑通：指标能不能正确算出、阈值能不能产出明确结论、配额不足时流程会不会报错。
2. 项目方已决定先用预测数据推进产品方案阶段，本目录是该决策的输入。决策记录见 `04-决策记录/决策日志.md` 的 ADR-010。

## 禁止用途

- 不得把这里的数据填入 `02-需求调研/证据台账.csv` 的 E 系列编号
- 不得作为需求已被验证的证据，用于论证 799 元定价或 15 万台目标
- 不得出现在对外材料、投资人材料、渠道谈判材料或媒体报道中

## 防误用设计

- 数据文件每一行都带 `数据性质` 字段，值固定为 `模拟`。任何按该字段过滤的分析都会自动排除这些记录。
- 分析结论使用 `PE` 前缀编号，与实证证据的 `E` 编号分离。
- `02-需求调研/调研分析-预测版.md` 文件名带「预测版」，正文第 1 节和第 12 节重复声明其性质。

## 真实数据到位后

真实数据回收完成后，用同一套分析脚本重跑，对比两版差异，然后把本目录归档，避免与真实数据混淆。
