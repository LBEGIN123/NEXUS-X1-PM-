# 提示词：用户评价挖掘

这是证据的主力来源，必须并行：

```text
读 AGENTS.md 和 02-需求调研/证据台账.csv。

任务：为 C01–C08 每款竞品挖掘真实用户评价，产出一批带编号的证据。

1. 每款开一个子代理，每个子代理负责一款，独立完成。
2. 每款至少读 300 条评价，来源覆盖：电商平台评价、社区讨论、评测视频评论区。
3. 每个子代理返回两类结果：
   - 高频痛点：出现次数 + 有代表性的原文摘录 + 来源链接 + 采集日期
   - 故障模式：使用多久后出现、故障表现、售后处理结果
4. 只记录真实用户原话，不要转述成概括性表述。
5. 汇总后写入 02-需求调研/证据台账.csv，证据编号从 E001 连续编号，不要重号。
6. 最后按出现频次给出排名前十的痛点，注明每条的支撑证据编号。

注意区分「刚开箱的抱怨」和「使用半年后的抱怨」，后者更值钱。
```
