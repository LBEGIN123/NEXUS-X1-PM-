# 提示词：竞品扫描

在新任务里粘贴：

```text
读 AGENTS.md 和 00-项目简报/项目简报.md。

任务：完成跨平台游戏手柄的竞品扫描，把 01-竞品分析/竞品清单.csv 填满。

1. 拆成 4 个子代理并行查，每个只负责一类，避免重复劳动：
   ① 三大主机官方手柄（Sony / Microsoft / Nintendo）
   ② 国产第三方（北通 / 飞智 / 盖世小鸡 / 八位堂）
   ③ 海外第三方（PowerA / 8BitDo / Razer / Turtle Beach）
   ④ 手机夹持式与掌机用手柄
2. 每款必须拿到：支持平台、连接方式、当前价格（写采集日）、按键数、摇杆方案（碳膜/霍尔/TMR）、扳机类型、背键、陀螺仪、震动方案、轮询率或延迟、续航、重量、尺寸。
3. 拿不到的字段写「未获取」，禁止猜测或填行业平均值。
4. 每条数据标来源编号，来源清单写到 01-竞品分析/竞品分析.md 末尾。
5. 最后单独给一段 300 字以内的格局小结：市场已经做烂了什么、还没做好的什么。

等所有子代理返回后再汇总。结论必须写回文件，不要只在对话里说。
```

关键是第 1 条。不拆子代理的话，8 款手柄的顺序查询会塞满主对话，后面几款的质量会明显下降。
