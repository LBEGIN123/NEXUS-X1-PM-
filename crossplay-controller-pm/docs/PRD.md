## 1. 结论摘要

NEXUS X1 以“跨设备保留同一套手感”为核心价值。第一版不做全平台无条件的无线兼容，而是明确交付 PC、SteamOS、Switch、iOS、Android 的无线能力，以及 Xbox 有线兼容能力。

产品差异化由三层组成：

- 平台身份层：自动识别目标平台，恢复上次连接通道、布局和手感。
- 配置身份层：按键、曲线、扳机、振动和体感配置随账号同步。
- 可验证链路层：用输入测试、回报率、丢包和电池状态证明低延迟，而不是只宣传芯片参数。

产品的商业目标是进入 129-189 美元高端价格带，同时避免与 Xbox Elite Series 2、DualSense Edge 在单一生态内正面竞争。首发核心人群是每周在两个以上平台之间切换的融合玩家。

## 2. 背景与机会

### 2.1 用户问题

多设备玩家现在需要管理多套连接、多套配置和多套按键记忆。官方旗舰手柄在单一生态中体验完整，但跨生态后，玩家仍需要重新配对、重新映射和理解平台布局。挑战者品牌在 TMR 摇杆、1000Hz、霍尔扳机和软件调参上参数领先，但配置身份和连接状态仍分散在多个工具中。

### 2.2 机会

如果系统能够把目标平台和玩家配置抽象为稳定身份，平台切换就不再是一次重新学习，而是一次状态恢复。该能力可以同时服务三类用户：

- 跨端融合玩家：减少切换时间与误操作。
- 竞技玩家：保留曲线、背键和宏，并在赛前验证链路。
- 移动与云游戏玩家：降低首次连接和日常恢复的认知负担。

### 2.3 不解决什么

第一版不解决 PS5 原生无线兼容、不提供可自由刷写固件的开放平台、不开放用户自行拆解整机，也不把云游戏内容运营纳入产品范围。

## 3. 目标与成功指标

### 3.1 用户目标

- 玩家可以在 20 秒内完成首次连接与一次按键确认。
- 玩家切换平台的中位耗时不超过 5 秒。
- 玩家在多设备上恢复同一游戏的配置时，不需要逐项重新设置。
- 玩家能理解输入测试结果，并据此选择竞技模式或续航模式。

### 3.2 业务目标

- 首发前完成 240 份有效问卷、12 场访谈和 100 名种子用户测试。
- 首发 90 天目标销量达到项目批准量的 60%。
- 退货率低于 5%，12 个月摇杆漂移售后报告率低于 0.8%。
- 伴侣 App 首月活跃率 >= 55%，配置同步用户 4 周留存相对提升 >= 15%。

### 3.3 非目标

- 不以开放脚本运行环境换取极客用户的短期传播。
- 不用灯光、屏幕和复杂动画稀释竞技链路的稳定性。
- 不在第一版追求所有平台的无线与高级反馈。

## 4. 用户画像与核心任务

### 4.1 跨端融合玩家

情境：工作日晚上在 PC 玩射击，周末在客厅主机继续动作游戏，临时使用掌机或平板云游戏。

任务：当我换到另一台设备时，我希望手柄自动恢复我的按键和手感，不需要重新配对和记忆布局。

成功信号：切换后 5 秒内可操作，背键和扳机模式与上次一致。

### 4.2 竞技型玩家

情境：为不同游戏保存曲线、死区、扳机模式和宏，比赛前需要确认输入链路稳定。

任务：当我进入比赛前，我希望知道当前是何种连接、是否存在丢包，以及配置是否生效。

成功信号：输入测试给出明确结论，异常时提供可执行修复动作。

### 4.3 移动与云游戏玩家

情境：使用手机、平板或电视盒玩云游戏，设备频繁休眠和恢复。

任务：当我拿出设备时，我希望手柄快速重连并继续上一次的配置。

成功信号：休眠恢复不需要重新搜索设备，失败时自动回退到有效通道。

## 5. 用户旅程

### 5.1 首次连接

1. 用户连接充电底座或打开手柄蓝牙。
2. 长按 NEXUS 键 3 秒。
3. App 扫描设备，识别平台和固件版本。
4. 用户确认目标平台。
5. App 推荐一类预设，用户完成按键与振动确认。
6. 设备保存平台身份和个人配置。

异常：

- 发现多个平台可用时，默认选择最近连接平台并允许切换。
- 固件版本过低时，先完成连接，在后台提示升级，不阻塞基础使用。
- 蓝牙权限被拒绝时，提供有线或 2.4G 路径，不重复弹出系统权限。

### 5.2 日常平台切换

1. 用户按底部平台键。
2. 手柄灯带显示目标平台颜色。
3. 固件切换协议与配置。
4. App 显示连接与配置恢复结果。
5. 用户直接进入游戏。

异常：

- 目标平台 3 秒不可达，回退到上一个有效通道，并记录诊断事件。
- 配置版本冲突时，以设备本地配置为当前会话，云端版本在后台等待用户选择。
- 电池低于 10% 时，暂停配置下载，优先保证输入与连接。

### 5.3 手感调校

1. 用户在设备中心选择平台与游戏模板。
2. 进入实验室调整摇杆、扳机、按键、振动与体感。
3. 实时预览手柄响应动画。
4. 保存为个人配置并同步。
5. 可选择覆盖设备内 5 个快捷配置之一。

异常：

- 曲线产生无效区间时阻止保存并指出冲突。
- 宏超过固件长度限制时提示拆分或改为组合键。
- 同步失败时本地保存成功，状态标记为“待同步”。

## 6. 功能范围与优先级

### 6.1 P0：首发必须

| 编号 | 需求 | 用户价值 | 验收口径 |
| --- | --- | --- | --- |
| FR-001 | 平台身份与切换 | 降低跨设备摩擦 | 5 个无线平台均有保存与恢复；中位切换 <= 5 秒 |
| FR-002 | 0 秒配对体验 | 首次使用可独立完成 | >= 85% 测试用户独立完成；中位耗时 <= 20 秒 |
| FR-003 | 5 个机身配置 | 不打开 App 也能切换常用手感 | 颜色与脉冲明确区分；切换反馈 <= 300ms |
| FR-004 | 按键与宏映射 | 满足竞技与动作游戏 | 每个可映射键支持单击、长按、双击、组合键 |
| FR-005 | 摇杆曲线与死区 | 解决瞄准与漂移体验 | 中心/外圈死区、曲线、反死区均可保存和回滚 |
| FR-006 | 双模式扳机 | 覆盖射击与竞速 | 线性霍尔与微动模式切换可靠；无卡滞与误触 |
| FR-007 | 输入链路测试 | 让低延迟可感知 | 展示连接、回报、抖动、丢包与电池结论 |
| FR-008 | 账号同步与导入导出 | 保留玩家配置资产 | 登录后可同步；离线时本地可用并自动补传 |
| FR-009 | 固件升级 | 修复兼容与增加模板 | 支持失败回滚；升级中断不使设备变砖 |
| FR-010 | 售后诊断 | 降低沟通成本 | 一键生成去敏日志、连接记录、配置版本与电池曲线 |

### 6.2 P1：验证后发布

| 编号 | 需求 | 条件 |

| FR-101 | 社区模板市场 | 社区内容审查与版权流程通过 |
| FR-102 | 游戏自动识别 | 平台允许读取前台游戏且用户授权 |

### 6.3 P2：不做

- 手柄屏幕。
- 用户自行更换电池或拆解主板。
- 开放 Lua、Python 等任意脚本环境。
- PS5 自适应扳机模拟。
- 第一版订阅制高级配置。

## 7. 平台与连接

| 平台 | 通道 | 首发承诺 | 限制 |
| --- | --- | --- | --- |
| Windows 10/11 | 2.4G / 蓝牙 / USB-C | XInput、DInput、1200Hz 测试目标 | 某些启动器不传递背键，需映射到标准键 |
| SteamOS | 2.4G / 蓝牙 / USB-C | Steam Input 可见并支持背键映射 | 系统版本更新可能改变识别结果 |
| Xbox Series X / Xbox One | USB-C | 标准 Xbox 手柄行为 | 第一版不承诺无线与官方高级功能 |
| Switch | 蓝牙 | 基础输入、唤醒、体感 | 平台键位按 Nintendo 布局显示 |
| iOS / iPadOS | 蓝牙 | 基础输入、配置恢复 | 后台宏受到系统限制，不承诺 |
| Android | 2.4G / 蓝牙 / USB-C | 基础输入、配置恢复、体感 | 厂商省电策略可能终止后台连接 |

## 8. 硬件需求

| 模块 | 需求 |
| --- | --- |
| 摇杆 | TMR 磁阻模块，12-bit ADC，4096 级输出，回中误差与线性度进入 EVT 门禁 |
| 扳机 | 霍尔线性模式与微动短行程模式，双模切换可承受 100 万次操作 |
| 按键 | ABXY 光学微动，方向键独立触点，肩键静音微动 |
| 背键 | Core 2 个，Pro 4 个；可禁用，默认不映射避免误触 |
| 体感 | 6 轴，支持 PC 与 Android 映射；iOS 仅基础姿态 |
| 振动 | 双握把线性马达 + 双扳机马达，支持关闭和强度分级 |
| 电池 | 1200mAh，35 小时目标续航；低电量不降低输入采样率 |
| 连接 | USB-C、2.4G 私有通道、Bluetooth 5.3 |
| 底座 | USB-C 上行、2.4G 中继、充电、dongle 收纳 |
| 灯光 | 低亮竞技模式、完全关闭、平台身份颜色 |
| 维护 | Pro 摇杆模块可更换；官方维修点可更换电池与主板 |

## 9. 软件信息架构

### 9.1 设备中心

- 当前平台、连接状态、电量、延迟评级。
- 切换平台、重新连接、固件更新。
- 输入测试与故障诊断入口。

### 9.2 配置中心

- 推荐预设：射击、动作、竞速、格斗、云游戏、日常。
- 我的配置：平台、游戏、最近使用、同步状态。
- 导入导出：文件、二维码、社区模板。

### 9.3 实验室

- 摇杆曲线与死区。
- 扳机模式与响应区间。
- 按键映射、组合键、宏。
- 振动、体感、灯光和竞技模式。

### 9.4 支持

- 去敏诊断日志、保修、维修点、配件、连接指南。

## 10. 关键交互规则

### 10.1 平台切换

- 切换按钮在所有核心页面可访问，不允许藏在二级菜单。
- 当前平台始终显示在顶部。
- 切换过程中禁止重复提交。
- 成功后显示恢复结果，失败后 1 秒内回退并给出原因。

### 10.2 配置冲突

- 本地配置优先级高于云端配置。
- 冲突不自动覆盖，只呈现“保留本地”“使用云端”“另存为新配置”。
- 宏和按键映射必须显示影响范围。

### 10.3 输入测试

- 测试持续 10 秒，过程允许取消。
- 结果分为“竞技”“稳定”“需优化”三档，不只展示原始数字。
- 丢包或抖动异常时，给出有线、2.4G、关闭灯光等可执行建议。

## 11. 数据与隐私

采集：

- 设备型号、固件、平台、连接通道。
- 输入测试摘要、错误码、连接时长。
- 配置类型、功能入口与匿名操作事件。

不采集：

- 游戏画面、音频、聊天内容。
- 原始按键序列，除非用户主动导出诊断且看到去敏预览。
- 联系人、精确位置、广告标识符。

数据保留：

- 诊断日志默认 30 天。
- 用户账号配置在账号删除后 30 天内清除。
- 社区宏保留作者、版本、平台兼容与举报记录。

## 12. 埋点与实验

| 事件 | 触发 | 关键属性 |
| --- | --- | --- |
| `pairing_started` | 用户开始首次连接 | platform, channel, firmware |
| `pairing_completed` | 完成按键与振动确认 | duration, attempts, error_code |
| `platform_switch` | 发起平台切换 | from, to, channel |
| `platform_switch_result` | 切换结束 | success, duration, fallback |
| `profile_restore` | 配置恢复 | platform, profile_type, conflict |
| `input_test_result` | 输入测试完成 | grade, polling, jitter, packet_loss |
| `diagnostic_export` | 生成诊断日志 | reason, redaction_preview |

实验：

- A/B 比较“产品名 + 平台名”与“目标设备图”哪种切换表达更快。
- 比较默认进入推荐预设与直接进入高级配置对首次完成率的影响。
- 比较输入测试三档结论与原始数值的信任度。

## 13. 异常与降级

| 异常 | 降级方案 | 用户提示 |
| --- | --- | --- |
| 2.4G 干扰 | 自动跳频，仍失败则建议切换蓝牙或有线 | 展示丢包和建议动作 |
| 蓝牙断连 | 保留配置，自动重连 3 次 | 不丢失当前配置 |
| 云同步失败 | 本地保存，稍后补传 | 状态显示“待同步” |
| 固件升级失败 | 自动回滚上一版本 | 提供重试和有线升级 |
| 电池过低 | 关闭灯光与振动，保持输入采样 | 提供省电模式说明 |
| 平台不可用 | 回退到最近有效通道 | 说明平台原因，不重复弹窗 |

## 14. 验收标准

### 14.1 产品验收

- 5 个无线平台完成连接、切换、配置恢复和异常回退闭环。
- Core 与 Pro 均能通过 100 万次按键、100 万次扳机和 200 万次摇杆转动测试。
- 20 名目标用户中至少 14 名可独立完成首次连接与平台切换。
- 100 名种子用户连续使用 4 周，无 P0 数据丢失和不可恢复的固件故障。

### 14.2 质量门禁

- 2.4G 70% 电量、典型干扰环境下连续 4 小时无断连。
- 1000 次连接切换失败率低于 0.5%。
- 输入测试与实验室仪器在测试口径下的结果稳定一致。
- App 冷启动到设备状态可见低于 2 秒。
- 配置保存到设备生效的成功率 >= 99.5%。

## 17. 上线后观察

前 30 天按天观察，31-90 天按周观察：

- 首次连接完成率与失败原因。
- 平台切换成功率、回退率、平均耗时。
- 配置同步失败与冲突处理选择。
- 输入测试触发率和优化建议点击率。
- 售后连接、摇杆、扳机、电池与固件问题占比。
- App 崩溃、蓝牙断连和平台识别错误。

如果平台切换失败率超过 1%，暂停扩展新平台，优先修复连接适配层。如果配置同步对 4 周留存没有显著提升，将其降为免费增值功能，不继续投入社区市场。
