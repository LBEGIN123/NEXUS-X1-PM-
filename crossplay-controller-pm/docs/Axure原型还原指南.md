# NEXUS X1 Axure 原型还原指南

## 目标

该指南用于将 `prototype.html` 的交互逻辑还原到 Axure RP，并保持以下原则：

- 一个页面只承载一个主要任务，状态通过动态面板处理。
- 所有平台切换、连接状态和配置值使用全局变量，不在每个页面重复硬编码。
- 原型先证明核心链路，再补充视觉动效，避免点击演示掩盖状态问题。

## 画布与网格

- 桌面画布：1440 × 1024。
- 应用内容区域：1240 × 860，居中，四周保留 32px。
- 最小点击区域：44 × 44。
- 网格：8px；组件间距使用 8、16、24、32。
- 圆角：控件最多 8px；摇杆、按键和状态点使用圆形。

## 页面 01A：设备中心与平台切换

### 主体组件

- 顶部状态条：Logo、当前平台、连接通道、电量、账号。
- 左侧导航：设备、配置、映射、手感、测试、支持。
- 中央手柄渲染：按钮和摇杆分组为可点击热区。
- 右侧检查器：平台、连接、配置、延迟、电量、最近同步。
- 底部主行动：`启动 0 秒配对`。

### 交互

| 触发 | 条件 | 动作 |
| --- | --- | --- |
| 点击平台按钮 | 非当前平台 | 设置 `gPlatform`，更新颜色和文案，触发配对覆盖层 |
| 点击当前平台 | 当前平台 | 不切换，显示短暂“已在该平台”提示 |
| 点击手柄热区 | 任意 | 打开右侧检查器对应模块 |
| 点击重新连接 | 已断连 | 重置连接状态并进入 01B |
| 点击固件提示 | 有更新 | 跳转 01D |

### 状态

- PC：青色，2.4G，FPS_NEON，1000Hz。
- Xbox：绿色，USB-C，XBOX_COMPAT，250Hz。
- Switch：红色，蓝牙，SWITCH_TEMPLATE，125Hz。
- SteamOS：紫色，2.4G，STEAM_DECK，1000Hz。
- Mobile：黄色，蓝牙，CLOUD_READY，250Hz。

## 页面 01B：配对覆盖层

### 步骤

1. 唤醒手柄。
2. 检测目标平台。
3. 建立连接。
4. 恢复个人配置。
5. 输入检查通过。

### 交互

- 覆盖层打开后自动推进，每步 520ms。
- 完成后显示“进入设备中心”，自动关闭。
- 关闭时保留当前平台和配置。
- 步骤 3 失败时进入 01C。

### 动效

- 灯带从中心向两侧填充。
- 步骤节点按完成状态改变颜色。
- 不使用大幅位移动画，保证演示稳定。

## 页面 02A：推荐预设

卡片包含：

- 预设名、适用游戏、平台、最近使用。
- 摇杆曲线缩略图、扳机模式、背键数量。
- 主要行动：应用；次要行动：预览、复制。

点击应用后：

- 保存到当前平台配置。
- 显示“已应用，可撤销”的 5 秒提示。
- 可选择写入机身配置 1-5。

## 页面 03A：按键映射

左侧为手柄热区和当前选中键，中央为映射列表，右侧为行为设置。

行为类型：

- 标准键。
- 组合键。
- 双击。
- 长按。
- 宏。
- 禁用。

冲突规则：

- 同一行为绑定到两个物理键时允许保存，但在使用提示中标记。
- 背键默认禁用，首次点击时提供“从标准键复制”。
- 宏超过 32 步时阻止保存并进入 03C。

## 页面 04A：摇杆曲线

控件：

- 中心死区：0-20%。
- 外圈死区：80-100%。
- 曲线：低速、线性、高速、自定义。
- 反死区：0-15%。

实时反馈：

- 手柄渲染中的摇杆位置随滑块变化。
- 曲线预览显示输入与输出关系。
- 无效组合阻止保存，并高亮冲突字段。

## 页面 05A：输入测试

流程：

1. 选择 5 秒快速测试或 10 秒完整测试。
2. 页面提示按键和摇杆动作。
3. 进度条按时间推进。
4. 完成后进入 05B 或 05C。

结果结构：

- 总评级：竞技 / 稳定 / 需优化。
- 回报率、抖动、丢包、电池影响、连接通道。
- 建议动作：切换 2.4G、使用有线、关闭灯光、更换位置。

## 页面 06A：移动伴侣

手机画布：390 × 844。

- 顶部显示手柄连接和电量。
- 中央显示当前平台与配置。
- 底部页签：设备、配置、测试、支持。
- 快速校准入口：摇杆中心、扳机起止点、振动强度。

## Axure 原型交互检查表

- [ ] 所有平台都能改变全局变量，并刷新顶部状态和右侧检查器。
- [ ] 平台切换过程不可重复点击。
- [ ] 配对失败与超时都有恢复路径。
- [ ] 配置冲突不自动覆盖。
- [ ] 所有滑块都有数值反馈和保存状态。
- [ ] 输入测试有运行、完成、失败三种状态。
- [ ] 移动端画布与桌面端使用同一组变量。
- [ ] 返回按钮不丢失未保存的配置，或明确提示放弃。
- [ ] 使用 1440 × 900 和 390 × 844 两种画布演示。

## 演示路径

1. 从 PC 设备中心开始，展示 2.4G 与 FPS 配置。
2. 点击 Switch，展示 0 秒配对、蓝牙通道与布局恢复。
3. 进入映射实验室，把 L4 设置为“跳 + 蹲”组合键。
4. 进入摇杆曲线，调整死区并保存为“我的射击配置”。
5. 进入输入测试，得到“竞技”评级。
6. 打开移动伴侣，展示同一账号下的配置已同步。
7. 在 PRD 页说明第一版为何不做 Xbox 无线。
